# Recorded answers

`decisions.json`, `oracle.json`, `mixed-oracle.json` and `house-oracle.json` are
Jev's answers to this rig's own questions, captured from real runs so that the
lab works with no API key. Each one records the policy fingerprint it was asked
under; a criteria edit retires every file filed under the old one.

`policy-aligned.json` is the criteria the lab's last section arrives at. It came
from the same GEPA search `jeva` runs, scored by real Jev calls, with the labels
supplied by a model applying the house rule rather than by a person. Every
number the lab quotes about it is measured; the labels behind it are not a
human's judgement, and the lab says so where it offers the file.

`mixed-oracle-aligned.json` is Jev's answers under those aligned criteria.
